# World Tourism Map Explorer 🌍✨

**World Tourism Map Explorer** is an interactive tourism discovery web project created by **Bhuvaneshwaran R**. It is designed as a creative portfolio demo for tourism companies, travel agencies, holiday brands, hotels, destination marketing teams, and travel-tech businesses.

The project helps users visually explore famous travel destinations across the world using an interactive map, destination filters, destination preview cards, map layers, auto-tour mode, and direct map links.

> This project is built as a personal portfolio and promotional demo to showcase my skills in web development, travel technology, UI/UX thinking, digital marketing, and tourism-focused creative tools.

## 🚀 How to Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No build tools are required.

```bash
git clone https://github.com/bhuvanbhuvi043/world-tourism-map-explorer.git
cd world-tourism-map-explorer
```

Then open:

```text
index.html
```

---

## 🌐 How to Deploy With GitHub Pages

1. Create a new public GitHub repository.
2. Upload `index.html`, `README.md`, `LICENSE.md`, and `NOTICE.md`.
3. Go to repository **Settings**.
4. Click **Pages** from the left sidebar.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select branch: `main`.
7. Select folder: `/root`.
8. Click **Save**.
9. Wait for GitHub to generate the live site link.
